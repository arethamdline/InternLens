# Real postings (not committed)

Put the text of each real internship posting here as `<case-id>.txt`, for example `R01.txt`.

Everything in this folder except this README is git-ignored, because sites such as HKU NETjobs do not allow their job content to be copied or republished. Commit only the link and your labels in `eval/cases.json`. Each teammate who runs the evaluation needs their own local copy of these files.
